# Aprende Fazendo

Um output style para o Claude Code que faz o trabalho e te ensina no caminho, em português simples.

Criado por Enzo Barbatto ([@EnzoSparo](https://www.youtube.com/@EnzoSparo)).

## Como instalar

Cole isto no Claude Code:

```
Instala o output style "Aprende Fazendo": baixa o arquivo https://raw.githubusercontent.com/sparo-demonstracao/aprende-fazendo/main/aprende-fazendo.md exatamente como está (com curl, sem resumir) e salva em ~/.claude/output-styles/aprende-fazendo.md. Depois coloca "outputStyle": "Aprende Fazendo" no ~/.claude/settings.json sem apagar o resto, e me avisa pra reabrir o Claude Code.
```

Depois feche e abra o Claude Code de novo (ou comece uma conversa nova) e o estilo já vem ligado.

## Instalar sem o Claude

1. Baixe o arquivo [aprende-fazendo.md](aprende-fazendo.md) e salve na pasta `~/.claude/output-styles/` (no Windows: `C:\Users\SEU-USUARIO\.claude\output-styles\`).
2. Reabra o Claude Code, rode `/config` e escolha **Aprende Fazendo** em **Output style**.
